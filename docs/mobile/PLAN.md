## 产品边界
只交付 iOS、Android、HarmonyOS 手机 App。默认鸿蒙指原生 HarmonyOS，最低系统版本待确认。无需账户即可本机使用。离线指管理与查询本地数据，不含离线运行 AI 模型。当前 HTML 仅为设计评审载体，不是最终网站或 App 交付。

MVP：订阅新增/编辑/归档、周期与币种、续费提醒、用量快照、来源与时间、手动用量、平台连接状态、本地备份恢复。暂缓云同步、多人协作、订阅购买与自动取消、模型聊天。

真实用量能力逐个平台查官方接口验证。现有代码标记 MiniMax/DeepSeek 可直连，只是待复核线索，不作为已验证能力。消费订阅、API 消费、余额、Token、请求数及不同窗口分别展示；缺失值显示未知，不作零值，不混算百分比。混合币种按币种汇总；换算必须标注汇率来源与日期。

## UI 规格
导航：总览 / 订阅 / 用量 / 我的。续费清单放在总览，支出统计作为次级入口，减少底栏数量。订阅详情集中展示周期、价格、下次续费及用量。

视觉：纸白 #F6F8FC、墨蓝 #182640、主蓝 #315DCC、浅蓝 #E8EEFC、警示棕 #986017、分隔灰 #DCE3EF。中文采用系统无衬线，数字使用 tabular-nums；正文 15–16px、标题 26px；触控区域至少 44px。突出分窗口额度条与续费时间，避免把不同比例合成总额度。

原型使用虚构示例数据与固定 2026-10-29 快照。可切换四个导航、查看详情、添加模拟订阅、切换离线/空状态。所有原型更改仅存在内存，刷新即重置，不输入真实凭据。

状态：首次空白引导添加；离线显示上次记录时间；请求失败保留历史数据并允许重试；授权失效提示重新连接；无接口提供手动录入；余额不显示百分比；额度未知不绘制进度条。正式 App 编辑成功必须在设备持久化后反馈。离线不能显示同步成功。

## Pi 任务合同
每次委派包含 ID、批准 UI 版本、允许修改范围、依赖、禁止事项、测试、交付证据和停止条件。首次调用前检查当前 Pi 身份/版本/协议及可用能力；不读取或记录真实密钥，不改全局配置。按小批次执行，FX 阅读 diff、运行相关测试并检查交互，不以 Pi 自述作为完成证据。未经 FA 授权不提交或推送。

## 必测场景
- 飞行模式冷启动、增改归档及重启后数据保留；恢复网络不覆盖手动修改。
- 余额/Token/次数、5 小时/周/月窗口不混算；超额、未知、缓存过期正确显示。
- 网络超时、401、429、部分平台失败均保留最后成功快照；重试不重复写入。
- 月底/闰年/跨时区续费日期；通知拒绝后仍可使用其他功能。
- 三端安全区、软键盘、返回行为、大字体、屏幕阅读器、明暗主题。
- 导入损坏文件不覆盖原数据；备份默认不包含凭据，恢复前预览并确认。

待补充但不阻塞 V1 设计：首批平台与订阅类型、鸿蒙最低版本、是否需要跨设备同步。当前默认本机单用户、原生鸿蒙、无云同步。
